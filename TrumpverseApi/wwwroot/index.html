Api Dokumentasjon

Introduksjon

Denne dokumentasjonssiden er laget for å hjelpe deg med å forstå og bruke TrumpverseApi-et. Api-et gir omfattende CRUD-funksjonalitet for å administrere "thoughts" og tilhørende data. Alle forespørsler håndteres over HTTPS, og svar returneres i JSON-format.

TrumpverseApi-et tilbyr følgende nøkkelfunksjoner:

  • Hente alle "thoughts" eller filtrere etter ID eller kategori.
  • Opprette, oppdatere eller slette "thoughts" med enkle forespørsler.
  • Feilhåndtering med HTTP-statuskoder.

Thoughts

Det er totalt 8 thoughts sortert etter Id.

Thoughts schema

Key Type Description
Id Int Id til Innlegget
Heading String Overskriften til Innlegget
Content String Innholdet til innlegget
Category String Kategorien til Innlegget
Image String Bildet til innlegget

CRUD

Get all thoughts

Metode: GET

Henter en liste over alle innlegg/thoughts.

Endepunkt: api/Thought

Get a single thought by Id

Metode: GET

Henter et innlegg ved å bruke id som et parameter.

Endepunkt: api/Thoughts/{Id}

Get thought by category

Metode: GET

Henter alle innlegg/thought basert på kategori.

Endepunkt: api/Thought/GetByCategory/{category}

Create new thought

Metode: POST

Opretter et nytt innlegg/thought.

Endepunkt: api/Thought

Update new thought

Metode: PUT

Opptaderer et eksisterende innlegg/thought.

Endepunkt: api/Thought

Delete thought by Id

Metode: DELETE

Sletter et innlegg/thought basert på Id.

Endepunkt: api/Thought/{Id}

Image Upload

Metode: POST

Laster opp bilder til serveren.

Endepunkt: api/ImageUpload

Feilhåndtering

Alle endrepunktene returnerer statuskode 500 InternalServerError ved error.

                    {
                        "error": "Noe gikk galt"
                    }
